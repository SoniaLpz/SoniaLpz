### TravelCrew 

A collaborative application for planning trips in groups and invite with 100% automated invitation system. 
As part of a 3 people team : 

* Implemented a responsive theme management system for Light/Dark mode, developed the travel planning interface using React and Tailwind CSS. 
* Integrated a custom-built invitation form linked to Nodemailer. 
* Ensured seamless synchronization between the React frontend and Node.js backend for the authentication service. 

### PetAdopt

As part of a 3 people team, we implemented a comprehensive unit testing suite using TypeScript. 

* Designed test cases for the animal management controller and verifying authentication logic, for both user registration and login. 
* Integrated testing for the successful login flow and the dynamic display of the "Favorite Pets" list. 
* Collaborated to integrate E2E Testing using Cypress.
